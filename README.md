# 🚀 Inventra Nexus
### AI-Enabled Smart Inventory & Integrated Commerce System

**Inventra Nexus** is a web-based smart inventory management system designed to simplify inventory operations, manage suppliers, monitor stock levels, analyze business performance, and support demand forecasting.

The system provides a centralized dashboard with analytics, inventory tracking, reporting, and intelligent stock management features.

---

## 📌 Project Overview

Traditional inventory management often involves manual tracking, spreadsheet management, and time-consuming reporting.

Inventra Nexus aims to simplify these processes through a centralized web application that helps businesses manage products, suppliers, stock movements, and business insights efficiently.

## 🎯 Project Objectives

- Automate inventory management operations.
- Monitor product quantities and stock levels.
- Manage supplier information efficiently.
- Identify low-stock products.
- Support demand forecasting and inventory planning.
- Generate downloadable PDF and Excel reports.
- Provide visual business analytics through dashboards.
- Improve inventory accuracy and operational efficiency.

## ✨ Key Features

### 1. Authentication
- Login interface for system access.
- User authentication workflow.

### 2. Dashboard
- Business overview and KPI cards.
- Revenue and inventory analytics.
- Visual charts and graphs.
- Low-stock alerts.
- Generate Order functionality.

### 3. Product Management
- Add, view, update, and delete products.
- Maintain product details.
- Track product quantities and prices.
- Monitor inventory levels.

### 4. Supplier Management
- Maintain supplier information.
- Add and manage suppliers.
- View supplier details.

### 5. Demand Forecasting
- Forecasting interface for demand analysis.
- Visual representation of forecasting results.
- Forecast report export functionality.
- Supports inventory planning.

### 6. Reports & Analytics
- Business analytics dashboard.
- Revenue trend visualization.
- Sales category analysis.
- Top-performing product information.
- Recent transaction information.
- PDF report generation.
- Excel report generation.

### 7. Notification System
- Notification dropdown.
- Inventory-related alerts.
- User-action notifications.

### 8. Settings
- Dark and light theme switching.
- Currency selection (USD / INR).
- Account management options.
- Delete account functionality.

## ⚙️ Installation & Setup

### Prerequisites

Install the following before running the project:

- Node.js
- npm
- MongoDB Atlas account or MongoDB database
- Visual Studio Code

### Step 1: Clone the Repository

```bash
git clone https://github.com/kunalsadhudata/inventranexus.git
```

```bash
cd inventranexus
```

### Step 2: Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

Replace the MongoDB connection string with your own database connection string.

Start the backend:

```bash
npm start
```

Backend runs at:

`http://localhost:5000`

### Step 3: Setup Frontend

Open another terminal:

```bash
cd frontend
npm install
```

Start the React application:

```bash
npm start
```

Frontend runs at:

`http://localhost:3000`

### Step 4: Access the Application

Open your browser and visit:

`http://localhost:3000`

Make sure both frontend and backend servers are running.
